# Modern C++ Primer

[![License](https://img.shields.io/badge/License-CC--BY--SA%204.0-blue)](./LICENSE)

一个以认知阶段为主线的原创现代 C++ 教程。

**在线阅读：<https://dynilath.github.io/modern-cpp-primer/>**

## 三个主要目标

- **内容准确，尽量避免歧义** —— 概念首次出现时为了方便理解可能缩小范围或拆分，但引入的表述始终保持正确
- **跟随 C++ 标准** —— 需要时对特定平台环境进行说明
- **内容由浅入深，减少学习负担** —— 避免超过 1 章的提前引用，任何概念必须在本章中得到解释

## 本地开发

```bash
pnpm install
pnpm dev      # 开发服务器
pnpm build    # 构建到 dist/
pnpm preview  # 预览构建产物
```

基于 [Astro](https://astro.build) + [Starlight](https://starlight.astro.build) 构建。
